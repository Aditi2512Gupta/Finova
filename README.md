## 📖 Overview

Managing personal finances shouldn't be complicated.

**Finova** is an AI-powered finance companion that helps users track expenses, manage budgets, monitor financial health, analyze spending habits, and receive personalized recommendations from **Nova**, an AI financial assistant powered by **Gemini AI**.

Built with **Flutter** and **Firebase**, Finova focuses on delivering a premium user experience with modern UI, smooth performance, and intelligent financial insights.
